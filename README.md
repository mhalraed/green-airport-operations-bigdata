# AirGreenOps: Reducing Airport Ground Emissions Through Sustainable and Efficient Operations

MSc Data Science thesis, Emirates Aviation University.
Author: Abdulla Mohammed Abdulla Almulla.

This repository extends the AirGreenOps lakehouse built for EM06DS (Big Data Analytics and Data Visualisation, May 2026)
into a thesis-scale study of airport ground-operation emissions.

## Research questions
1. How do aircraft type, fuel use, operating weight, taxi time, weather and congestion influence ground emissions?
2. Which airports have better ground carbon performance under comparable conditions, and what are they doing differently?
3. Which changes can reduce emissions without increasing delays, extending turnaround times or restricting capacity?

| Layer | Tool |

## Notebooks (run in order)
| Notebook | Purpose |
|---|---|
| `01_airgreenops_ingestion_etl.ipynb` | Obtain and scrub: BTS, NOAA, OurAirports, aircraft reference → Bronze/Silver/Gold. Exploratory analysis. |
| `02_airgreenops_mlp_tuning_benchmark.ipynb` | Model: MLP training, tuning and scalability benchmark. |
| `03_airgreenops_app.ipynb` | Delay-risk model, explainability (XAI), Gradio dashboard (incl. RQ2 and RQ3 tabs). |
| `04_rq1_taxi_time_drivers.ipynb` | RQ1: taxi-time models (historical average, linear regression, gradient-boosted trees, MLP), SHAP, effect sizes. |
| `05_rq2_airport_comparison.ipynb` | RQ2: airport fixed effects under comparable conditions, robustness and year-to-year stability. |
| `06_rq3_operational_scenarios.ipynb` | RQ3: gate hold, single-engine taxi and ground power scenarios with sensitivity analysis. |
| `07_spark_scaling_benchmark.ipynb` | Spark scaling: data volume x cluster size. |
| `08_figures_tables.ipynb` | Thesis figures and tables from the result tables; multicollinearity (VIF) check. Output in `docs/figures/`. |

Notebooks 04-08 are generated by `scripts/build_notebook_0X.py` (run from the repository root).
The change log with reasons and measured effects is `docs/thesis_changes.md`.

The commits of 9 May 2026 hold the EM06DS submission (notebooks, figures and reports, now in `docs/em06ds/`).
Later commits record each thesis change, so the history shows what changed and why.

## Data sources
| Data | Source |
|---|---|
| Flight records 2023-2025 | U.S. Bureau of Transportation Statistics, TranStats On-Time Reporting |
| Hourly weather | NOAA National Centers for Environmental Information, Global Historical Climatology Network hourly (GHCNh) |
| Airports and runways | OurAirports |
| Aircraft by tail number | U.S. Bureau of Transportation Statistics, Schedule B-43 aircraft inventory |
| Engine idle fuel flow | ICAO Aircraft Engine Emissions Databank (EASA, v32) |
| CO2 factor | ICAO (3.16 kg CO2 per kg fuel) |

Details, versions and checksums of the frozen inputs are in `docs/data_sources.md`.

Emissions are estimated from reference values, not measured.
